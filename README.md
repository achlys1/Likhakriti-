#Likhakriti — Where Words Meet Code
Likhakriti is a living platform for poetry, literature, and creative expression. It serves as the digital home for the creative and technical works of Yashraj Sharma, blending the art of Hindi and English literature with modern AI-driven development.
✦ Features
AI Poetry Studio: An interactive space to generate original poems in Hindi, English, or Hinglish using AI, with options to customize style (Ghazal, Sonnet, etc.) and tone.
Book & Literature AI: A dedicated literary companion capable of discussing world classics, from Premchand to Shakespeare.
Professional Portfolio: Showcasing technical projects including Python-based lofi players, SQL database management, and SEO strategies.
Service Suite: A listing of freelance services in technical writing, web development, and LinkedIn growth strategy.
Curated Achievements: Verification of professional certifications from HarvardX and Stanford Online.
🚀 Technologies Used
Frontend: Semantic HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid), and Vanilla JavaScript.
Typography: Cormorant Garamond, DM Sans, and Caveat via Google Fonts.
Interactivity: Intersection Observer API for scroll animations and custom cursor logic.
Intelligence: Integrated with the Anthropic Claude API for literary and poetic generation.
🛠️ Deployment Instructions
This site is optimized for GitHub Pages. To get it running:
Rename the file: Ensure your main file is named index.html.
Repository Setup: Upload index.html to your GitHub repository.
Enable Pages:
Navigate to Settings > Pages.
Under Build and deployment, set the Source to "Deploy from a branch".
Select the main branch and the / (root) folder.
Click Save.
API Configuration: The AI features require a backend proxy or client-side key handling. Ensure your API environment variables are correctly configured if you are using a custom workflow.
